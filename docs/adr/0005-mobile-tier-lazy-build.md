# ADR 0005: Capability-based quality tier and lazy scene building

- Status: accepted (v6.0.0)
- Date: 2026-11-13

## Context

v5 built all 48 machines at boot. The hub drew 14,616 draw calls and 16.1 M triangles, kept 4,598 geometries resident, and took 70–134 s to boot under SwiftShader. The default tier was chosen by viewport width, so a phone in landscape (915 CSS px) got High (DPR 2, 4× MSAA, 4096² shadows).

## Decision

- **Device class.** `deviceClass` in `src/app/lab-main.js` uses `(pointer: coarse)`, `navigator.userAgentData.mobile`, `navigator.deviceMemory` and `hardwareConcurrency` to choose a default tier: Low, Medium or High. Width alone is never used. A `?q=low|medium|high|ultra` URL parameter overrides it, and the toolbar menu changes it at run time.
- **Lazy build.** Each machine is registered with a proxy box sized from `src/app/hub-proxy-sizes.js` (generated by `tools/gen-hub-proxy-sizes.mjs`). Its full kit is built on first select (`ensureBuilt`). In proxy mode, geometry for machines you have left is freed least-recently-used (2 kept on phones, 6 elsewhere).
- **Hub modes.** `?hub=proxy` (the default on phones) shows the proxies. `?hub=full` (the default on desktop) shows the hub at once and builds the real machines in `requestIdleCallback` slices.
- **Tiers.** Low has no post-processing. Medium adds bloom and SMAA. High adds GTAO, close-up depth of field, 4× MSAA and 2048² shadows. Ultra supersamples past `devicePixelRatio`, capped at 3840×2160 pixels and the GPU's max texture size.
- **Touch.** On coarse pointers, buttons and chips are at least 44 px, the toolbar collapses behind a button, and the info panel becomes a slide-over drawer in landscape. Hints say pinch/drag instead of scroll/click.

## Consequences

- Proxy hub at Low, 1280×720 under SwiftShader: 66 draw calls, 31,022 triangles, 2.9 s to `__labStarted`.
- The first visit to each machine pays its build cost (typically 0.2–2 s).
- `hub-proxy-sizes.js` must be regenerated when a machine's footprint changes. A stale entry only mis-sizes a placeholder box.
