# Glossary of Architectural, Mainframe, Supercomputer, Quantum, Graphics & Acoustic Terms

| Term                                     | Definition in Computer Evolution Lab                                                                                                                                                                                                  |
| :--------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **`ACESFilmicToneMapping`**              | Academy Color Encoding System filmic HDR-to-SDR curve configured at `0.96` exposure in `src/app/lab-main.js` so emissive LEDs, vacuum-tube filaments, and white keycaps retain highlight detail without clipping.                     |
| **Branch History Table (`BHT`)**         | 64-entry 2-bit saturating counter predictor (`SN`, `WN`, `WT`, `ST`) in `RV32ModernSystem` (`src/sim/riscv-modern-pc.js`) predicting conditional `RV32I` branches with a 2-cycle flush penalty on misprediction.                      |
| **`CDR`-Coding (`Symbolics 3600`)**      | Hardware 2-bit list compaction (`lisp83`, 1983) encoding `CDR-NEXT` and `CDR-NIL` directly inside a 36-bit tagged word (`2b CDR + 4b Tag + 30b Payload`), halving cons-cell memory footprint.                                         |
| **Channel Command Word (`CCW`)**         | Autonomous I/O channel instruction introduced by IBM System/360 (`s360`, 1964) allowing dedicated tape, disk, and line-printer channels to DMA records into main core storage concurrently with CPU execution.                        |
| **Clements Mesh**                        | Universal `N×N` rectangular Mach–Zehnder interferometer waveguide arrangement (`src/sim/core-simulators.js`, `photonic`) implementing arbitrary unitary matrix-vector multiplication (`U·x`) via optical phase interference.          |
| **Cross-Section Slicer**                 | Real-time 3D `THREE.Plane` hardware clipping system (`CrossSectionSlicer` in `src/graphics/studio-stage.js`) with a CAD laser-reticle millimeter grid, cutting along `X`, `Y`, or `Z` while updating 3D raycasting.                   |
| **Dragonfly (`UGAL`)**                   | Three-hop hierarchical optical supercomputer interconnect (`exascale`, HPE Slingshot) using Universal Globally Adaptive Load-balanced routing to switch dynamically between minimal and non-minimal paths under congestion.           |
| **`HalfFloatType` MSAA**                 | 16-bit floating-point multisampled (`samples: 4`) WebGL2 render target used by `StudioFX` (`src/graphics/studio-stage.js`) to eliminate 8-bit color banding and 1-pixel polygon edge aliasing simultaneously.                         |
| **`HardWiredNetlistSolver`**             | Universal 6-gate full-adder / reversible Feynman–Toffoli transistor & gate solver (`src/layers/hardwired-gate-engine.js`) evaluating Boolean truth, `V_OH`/`V_OL`, `t_pd`, and `½CV²` across all 8 physical switching families.       |
| **Heisenberg Exchange & `PSB` (`²⁸Si`)** | Loss–DiVincenzo spin-qubit entangling interaction `U_ex(θ) = exp(-i(θ/4)σ·σ)` (`qspin`) paired with Pauli Spin Blockade (`PSB`) singlet-to-`(0,2)` tunneling readout at `1.2 K` in isotopically purified `²⁸Si/SiGe`.                 |
| **Majorana Zero Mode (`MZM`)**           | Topologically protected `E ≈ 0` Bogoliubov quasiparticle localized at the ends of a 1D Kitaev p-wave nanowire (`qtopo`, `\|μ\| < 2t`); braiding `σ₁, σ₂` executes non-Abelian Clifford gates immune to local parity-conserving noise. |
| **Measurement-Based QC (`MBQC`)**        | Photonic quantum paradigm (`qphotonic`) in which computation proceeds by single-photon `XY(α)` SNSPD measurements and nanosecond electro-optic Pauli feedforward across an entangled cluster state (`\|G₄⟩`).                         |
| **`MESI` Snooping Coherence**            | Four-state (`Modified`, `Exclusive`, `Shared`, `Invalid`) multiprocessor cache coherence protocol (`sun90`) maintaining uniform shared memory across symmetric RISC CPUs over a snooped split-transaction bus.                        |
| **MMIO (`0x20000000`)**                  | Memory-Mapped I/O address window in `RV32ModernSystem` bridging 32-bit RISC-V CPU store instructions (`SW`) to `uniform vec4 uCPU` inside the live WebGL2 GPU shader (`pc20`).                                                        |
| **Nested Page Tables (`EPT` / `RVI`)**   | Two-dimensional hardware MMU page walk (`blade04`, 2004+) translating Guest Virtual → Guest Physical → Host Physical addresses (`(4 × 5) + 4 = 24` cold memory references) without hypervisor `#PF` traps.                            |
| **Process Pairs & `WAL` (`Tandem`)**     | Share-nothing fault-tolerant OLTP architecture (`tandem77`, 1977) pairing active/backup processes across independent CPUs with Jim Gray Write-Ahead Logging (`UNDO`/`REDO`) for zero-data-loss failover.                              |
| **`qLDPC` & Rotated Surface Code**       | Quantum error-correcting codes (`qtransmon`, `qomega`) extracting X/Z stabilizer syndromes without collapsing encoded logical qubits, exponentially suppressing logical error rates `p_L ∝ (p / p_th)^((d+1)/2)` below threshold.     |
| **`Raft` Consensus**                     | Replicated state-machine consensus algorithm (`cloud10`) guaranteeing linearizable cluster logs via randomized leader election timeouts, majority quorums (`3/5`), and `AppendEntries` write-ahead log replication.                   |
| **`RAIM` Memory**                        | Redundant Array of Independent Memory (`zmain20`, IBM Telum z16) striping parity across 5 independent DIMM channels so an entire failed memory channel is reconstructed transparently with zero transaction downtime.                 |
| **Roofline Model**                       | Williams–Waterman–Patterson performance bound `P = min(P_peak, I × BW_mem)` (`src/app/compare-modal.js`, Tab 5) plotting attainable `GFLOPS` against Operational Intensity `I` (`FLOP/Byte`) across memory and compute ceilings.      |
| **Rydberg Dipole Blockade (`C₆/R⁶`)**    | Strong van der Waals interaction shift between laser-excited `⁸⁷Rb` Rydberg states (`qatom`) preventing simultaneous excitation within blockade radius `R_b`, realizing high-fidelity parallel two-qubit `CZ` phase gates.            |
| **Systolic Array (`Kung–Leiserson`)**    | Spatial 2D grid of rhythmically pulsed `MAC` processing elements (`systolic82`, 1982; modern TPUs/NPUs) passing operands and partial sums neighbor-to-neighbor to achieve `O(N)` arithmetic reuse per SRAM read.                      |
| **Thornton Scoreboard (`CDC 6600`)**     | First dynamic out-of-order hardware hazard scheduler (`cdc6600`, 1964) tracking `Fi/Fj/Fk/Qj/Qk/Rj/Rk` across 10 functional units to resolve `WAW` on Issue, `RAW` on Read Operands, and `WAR` on Write Result.                       |
| **Transverse-Field Ising Annealer**      | Adiabatic quantum optimization (`qanneal`) evolving `H(s) = -A(s)∑σᵢˣ + B(s)[∑hᵢσᵢᶻ + ∑Jᵢⱼσᵢᶻσⱼᶻ]` from a uniform superposition (`s=0`) toward the classical QUBO/Ising ground state (`s=1`) governed by minimum gap `Δ₀₁(s)`.        |
| **Vector Chaining & Predicated `SVE`**   | Seymour Cray's single-chime `FMUL→FADD` forwarding (`cray1`, 1976) and ARM Scalable Vector Extension's `WHILELT` per-lane `P0` predication (`fugaku20`, 2020) executing arbitrary-length vector loops with zero scalar cleanup.       |
| **Wafer-Scale Dataflow (`WSE`)**         | Monolithic `300 mm` reticle-stitched silicon fabric (`wse24`, 2024) keeping weights in single-cycle distributed SRAM (`21 PB/s`) while routing asynchronous color-tagged wavelets around lithographic defects via spare cores.        |
| **Wormhole Flit Routing (`ASCI Red`)**   | Low-latency MPP mesh packet switching (`ascired97`, 1997) splitting messages into `Head`/`Body`/`Tail` flits pipelined across `X→Y` dimension-ordered links without buffering entire packets at intermediate routers.                 |
