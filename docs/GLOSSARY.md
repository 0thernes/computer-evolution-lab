# Glossary of Architectural, Graphics & Acoustic Terms

| Term                             | Definition in Computer Evolution Lab                                                                                                                                                                                                     |
| :------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`ACESFilmicToneMapping`**      | Academy Color Encoding System filmic HDR-to-SDR curve configured at `0.96` exposure in `src/app/lab-main.js` so emissive LEDs, vacuum-tube filaments, and white keycaps retain highlight detail without clipping.                        |
| **Branch History Table (`BHT`)** | 64-entry 2-bit saturating counter predictor (`SN`, `WN`, `WT`, `ST`) in `RV32ModernSystem` (`src/sim/riscv-modern-pc.js`) predicting conditional `RV32I` branches with a 2-cycle flush penalty on misprediction.                         |
| **Clements Mesh**                | Universal `N×N` rectangular Mach–Zehnder interferometer waveguide arrangement (`src/sim/core-simulators.js`, `photonic`) implementing arbitrary unitary matrix-vector multiplication (`U·x`) via optical phase interference.             |
| **Cross-Section Slicer**         | Real-time 3D `THREE.Plane` hardware clipping system (`CrossSectionSlicer` in `src/graphics/studio-stage.js`) cutting through any active machine along the `X`, `Y`, or `Z` axis while updating 3D raycasting to ignore clipped surfaces. |
| **Data Forwarding (Bypass)**     | Hardware datapath multiplexers in `RV32ModernSystem` routing ALU results directly from `EX/MEM` back into `EX` without waiting for `WB`, avoiding read-after-write stalls on non-load instructions.                                      |
| **DishBrain (`bci`)**            | Closed-loop wetware biocomputer model (`100` Izhikevich spiking neurons on a TiN multi-electrode array) learning to return a Pong ball via reward-modulated spike-timing-dependent plasticity (`STDP`).                                  |
| **ENIG**                         | Electroless Nickel Immersion Gold surface finish procedurally rendered onto `2048×2048` FR-4 PCB SMD pads and plated through-hole vias (`src/graphics/pbr-materials.js`).                                                                |
| **Free-Induction Decay (`FID`)** | Decaying transverse magnetization signal induced in the NMR RF saddle coil (`quantum`) after tipping ¹H and ³¹P nuclear spins; Fourier-transformed live into spectral lines.                                                             |
| **`HalfFloatType` MSAA**         | 16-bit floating-point multisampled (`samples: 4`) WebGL2 render target used by `StudioFX` (`src/graphics/studio-stage.js`) to eliminate 8-bit color banding and 1-pixel polygon edge aliasing simultaneously.                            |
| **Load-Use Hazard**              | Pipeline stall triggered in `RV32ModernSystem` when an instruction immediately consumes a register destination (`rd`) loaded from memory (`LW`/`LH`/`LB`) in the preceding cycle.                                                        |
| **MMIO (`0x20000000`)**          | Memory-Mapped I/O address window in `RV32ModernSystem` bridging 32-bit RISC-V CPU store instructions (`SW`) to `uniform vec4 uCPU` inside the live WebGL2 GPU shader (`pc20`).                                                           |
| **MOnSter 6502 (`m6502`)**       | Transistor-scale discrete SMD reconstruction of the 1975 MOS Technology 6502 microprocessor paired in-scene with an authentic purple-brown ceramic DIP-40 6502 IC and 450× photolithographed die view.                                   |
| **`RV32IM`**                     | 32-bit RISC-V base integer instruction set (`RV32I`: 37 instructions) plus hardware integer multiply/divide extension (`RV32M`: `MUL`, `MULH`, `DIV`, `REM`), assembled and executed live in `pc20`.                                     |
| **Set-Associative Cache**        | Hardware cache simulator (`SetAssocCache` in `src/sim/riscv-modern-pc.js`) partitioning cache lines into indexed sets with Least-Recently-Used (`LRU`) replacement across `L1I` (4-way), `L1D` (4-way), and `L2` (8-way).                |
| **Toehold Strand Displacement**  | Enzyme-free DNA computing mechanism (`alife`, Seelig et al. 2006) in which single-stranded oligonucleotide inputs hybridize to exposed toehold overhangs and branch-migrate to release fluorescent output strands.                       |
